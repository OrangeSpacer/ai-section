# Live Metrics — AI Coding Task

## Задача

Необходимо реализовать компонент `LiveMetrics` на **React + TypeScript**.

В проекте уже реализован mock-источник данных `subscribeToMetrics`. Изменять его реализацию не требуется.

## Формат данных

Источник отправляет события следующего формата:

```ts
type Metric = {
  id: string;
  name: string;
  value: number;
  timestamp: number;
};
```

## Работа с источником

Для подписки на поток данных используется функция:

```ts
const subscription = subscribeToMetrics((metric) => {
  // новое событие
}, 10);
```

Второй аргумент определяет примерное количество событий в секунду.

Для остановки подписки:

```ts
subscription.unsubscribe();
```

## Требования

Реализовать компонент `LiveMetrics`, который:

1. Отображает актуальное значение каждой метрики.
2. Показывает направление изменения значения относительно предыдущего:
   - `↑` — значение увеличилось;
   - `↓` — значение уменьшилось;
   - `—` — значение не изменилось или предыдущего значения ещё нет.

3. Позволяет искать метрики по `name`.
4. Хранит историю максимум из **1000 последних событий**.
5. Корректно начинает и завершает работу с источником данных в соответствии с жизненным циклом компонента.

В интерфейсе достаточно вывести количество событий, находящихся сейчас в истории. Отдельно отображать все события истории не требуется.

Дизайн интерфейса **не оценивается** — достаточно минимальной разметки.

## Ограничения

- Можно создавать дополнительные компоненты, хуки и утилиты.
- Код должен быть таким, какой вы были бы готовы отправить на code review.
